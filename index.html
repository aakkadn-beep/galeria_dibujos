HTML Canvas y el contexto de renderizado 2D

¿Qué es HTML Canvas?

El canvas es una de las tecnologías mas ptentes para emplear el desarrollo web. Es un lienzo digital que permite crear gráficos de todo tipo a partir de primitivas lineas, circulos, cuadrados, rectaagulos.

Para utilizarlo, se coloca la etiqueta <canvas> en el documento HTML y se establece su ancho y alto. El elemento funciona como una superficie de dibujo, mientras que JavaScript proporciona las instrucciones para representar los gráficos.

¿Qué es el contexto de renderizado 2D?

El renderizado 2D crea imágenes a partir de elementos graficos planos a través de tecnicas especializadas.

El contexto de renderizado 2D es una interfaz de JavaScript que permite dibujar sobre un elemento Canvas. Se obtiene mediante el método getContext("2d"), que proporciona herramientas para establecer colores, crear formas y dibujar líneas o texto.

Ejemplo de código

<canvas id="miCanvas" width="400" height="200">
</canvas>

<script>
const canvas = document.getElementById("miCanvas");
const contexto = canvas.getContext("2d");

contexto.fillStyle = "lightblue";
contexto.fillRect(20, 20, 150, 80);

contexto.beginPath();
contexto.arc(250, 60, 40, 0, Math.PI * 2);
contexto.fillStyle = "orange";
contexto.fill();
</script>

Explicación del ejemplo

  • <canvas>: crea el área donde se dibujan los gráficos.
  • getElementById(): permite localizar el lienzo en el documento HTML.
  • getContext("2d"): obtiene las herramientas de dibujo bidimensional.
  • fillStyle: establece el color de relleno.
  • fillRect(): dibuja un rectángulo relleno.
  • arc(): define un arco que puede utilizarse para crear un círculo.
  • fill(): rellena la figura definida por el trazado actual.

Ventajas y aplicaciones

Canvas permite crear gráficos personalizados, juegos sencillos, visualizaciones de datos, animaciones y aplicaciones interactivas. Los dibujos se generan mediante instrucciones de código, por lo que pueden modificarse según las necesidades del proyecto.

En este proyecto se utiliza p5.js para simplificar la creación de los dibujos. Esta biblioteca puede trabajar con un elemento Canvas, aunque ofrece sus propias funciones para facilitar las operaciones gráficas.

La biblioteca p5.js

¿Qué es p5.js?

p5.js es una biblioteca de JavaScript diseñada para facilitar la creación de dibujos, animaciones y experiencias interactivas. Está orientada a la programación creativa y permite representar ideas mediante figuras geométricas, colores, texto e imágenes.

En lugar de utilizar directamente todos los métodos de Canvas, p5.js proporciona funciones más sencillas para dibujar formas, establecer colores y controlar la ejecución del programa. Esto permite concentrarse en el diseño y el comportamiento de los gráficos.

Funciones principales

  • setup(): se ejecuta una vez al iniciar el programa y permite preparar el lienzo y sus elementos.
  • draw(): se ejecuta repetidamente para generar los fotogramas de un dibujo o una animación.
  • createCanvas(): crea el área de dibujo y establece sus dimensiones.
  • background(): establece el color de fondo del lienzo.
  • fill(): define el color de relleno de las figuras.
  • ellipse(): dibuja una elipse o un círculo.
  • rect(): dibuja un rectángulo.
  • line(): dibuja una línea entre dos puntos.
  • noStroke(): desactiva el contorno de las figuras.

Ejemplo de código con p5.js

function setup() {
    createCanvas(400, 300);
}

function draw() {
    background(220);

    fill(30, 204, 91);
    ellipse(200, 150, 150, 100);

    fill(255, 255, 255);
    ellipse(170, 135, 25, 25);
    ellipse(230, 135, 25, 25);

    fill(0, 0, 0);
    ellipse(170, 135, 10, 10);
    ellipse(230, 135, 10, 10);
}

Explicación del ejemplo

La función setup() crea un lienzo de 400 píxeles de ancho por 300 píxeles de alto. Después, draw() establece el fondo gris y dibuja una figura verde que representa el cuerpo de una rana. Las elipses blancas y negras forman sus ojos.

Los valores de las funciones indican posiciones, dimensiones y colores. Por ejemplo, ellipse(200, 150, 150, 100) dibuja una elipse centrada en la posición horizontal 200 y vertical 150, con un ancho de 150 y un alto de 100 píxeles.

¿Cómo se utiliza p5.js en este proyecto?

En esta galería, p5.js se utiliza para crear cinco dibujos: Rana, Dientes de conejo, ¿Qué hay de cena?, Día nevado soleado y Muñeco de nieve. Cada dibujo tiene su propia función de JavaScript y utiliza instrucciones para definir sus figuras, posiciones y colores.

La función mostrarDibujo() determina qué dibujo debe mostrarse según el botón seleccionado. De esta manera, el usuario puede cambiar entre los dibujos sin tener que abrir una página diferente para cada uno.

p5.js y las animaciones

La función draw() se ejecuta repetidamente, lo que permite actualizar las posiciones, los colores y otros valores para producir animaciones. En esta galería, los dibujos son principalmente estáticos, por lo que no es necesario redibujar continuamente sus elementos.
